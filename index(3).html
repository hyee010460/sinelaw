🎯 休息站互動暖身：從「比值 $2R$」推導出「連比公式」

既然 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$，那三邊長之比 $a : b : c$ 會等於什麼呢？

小任務 1：已知 $\frac{a}{\sin A} = 2R$、$\frac{b}{\sin B} = 2R$、$\frac{c}{\sin C} = 2R$，若將分母移項乘過去，邊長 $a, b, c$ 可以怎麼表示？
因此：$a : b : c = 2R \sin A : 2R \sin B : 2R \sin C$
（把共同的 $2R$ 約掉）$\implies \mathbf{a : b : c = \sin A : \sin B : \sin C}$！
小任務 2【馬上試試看】：若一個三角形中 $\angle A = 30^\circ$、$\angle B = 90^\circ$，請問邊長比 $a : b$ 等於多少？
（提示：$a : b = \sin 30^\circ : \sin 90^\circ = \frac{1}{2} : 1$，並不是角度比 $30 : 90 = 1 : 3$ 喔！）
💡 提示： 把 $\frac{a}{\sin A} = 2R$ 兩邊同乘以 $\sin A$，就會得到 $a = 2R\sin A$。而在小任務 2 中，$a : b = \sin 30^\circ : \sin 90^\circ = \frac{1}{2} : 1 = 1 : 2$！
🎉 觀念完全打通！ 記住這個黃金準則：「邊長比等於正弦值之比 $a : b : c = \sin A : \sin B : \sin C$，絕不等於角度比！」 現在我們可以自信滿滿地進入最終實戰關卡了！
