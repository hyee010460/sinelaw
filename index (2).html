既然 a / sin A = b / sin B = c / sin C = 2R，那三邊長之比 a : b : c 會等於什麼呢？

小任務 1：已知 a / sin A = 2R 與 b / sin B = 2R，若將分母移項乘過去，邊長 a, b, c 可以怎麼表示？
因此：a : b : c = 2R sin A : 2R sin B : 2R sin C
（把共同的 2R 約掉）➔ a : b : c = sin A : sin B : sin C！
小任務 2【馬上試試看】：若一個三角形中 ∠A = 30°、∠B = 90°，請問邊長比 a : b 等於多少？
（提示：a : b = sin 30° : sin 90° = 1/2 : 1，並不是角度比 30 : 90 = 1 : 3 喔！）
💡 提示： 把 a / sin A = 2R 兩邊同乘以 sin A，就會得到 a = 2R sin A。而在小任務 2 中，a : b = sin 30° : sin 90° = (1/2) : 1 = 1 : 2！
